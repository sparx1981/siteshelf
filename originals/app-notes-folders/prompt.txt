Canvas & base: A calm paper-and-ink notes app filling a 1100px by 640px window (rounded 20px, 1px #d8d3c6 border, deep soft shadow) on a #e8e4da page. Pane colours: folder tree #f3efe4, notes list #fbf9f3, editor #ffffff. Ink #25221b (15:1), secondary #6a6454 (5.6:1), selection #fff1c9 with a 3px #e3a008 left bar, accent forest #2f6b4f (white on it 6.2:1), danger #b4372c. Invented notes app "Pocketpad".

Typography: "Newsreader" 500/600 for note titles and the editor body (editor 18px, 1.7); "Figtree" 500/600/700 for UI, folder names and meta (14 to 15px).

Layout: Three panes. Left (240px): app name, "New note" primary button, a tree with All Notes, Pinned, and folders Work, Home (with a nested Garden folder) and Ideas, each showing a note count, plus a "New folder" link that reveals an inline name field. Middle (320px): a search field with a clear button, a sort select (Updated, Created, A to Z) and the list of notes in the selected folder: pinned notes under a "Pinned" subheading, each row with title, a one-line preview, a relative time and a pin dot. Right: the editor with a toolbar (Pin, Move to folder select, Delete, word count, save status "Saved just now"), a large title input and a body textarea that grows. Eight invented seed notes across folders (for example "Planting calendar", "Q4 launch checklist", "Pasta night ideas", "Birthday gift list").

Interaction: Selecting a folder filters the list; the list is a listbox (role="listbox", options with aria-selected) with ArrowUp/Down moving and Enter focusing the editor; the tree is role="tree" with treeitems (aria-expanded for Home), ArrowUp/Down moving, Right/Left expanding and collapsing, Enter selecting. Typing in the editor updates the note live and shows "Saving..." then "Saved just now" after 600ms debounce, updating the relative times and word count; changes persist to localStorage (try/catch, with an in-memory fallback). Search filters title and body across the current folder with matches highlighted via <mark> in previews. New note creates "Untitled" in the current folder and focuses the title; Delete moves to a hidden Trash with a toast "Note deleted. Undo" (5s). Pin toggles with the list re-sorting (FLIP animation of rows, 200ms). Move to folder changes the folder with a toast. Ctrl or Cmd + N makes a new note and Ctrl or Cmd + F focuses search.

Responsive: Under 900px the folder pane becomes a slide-over drawer opened by a button; under 640px only one pane is visible at a time (folders, list, editor) with Back buttons and aria-live announcements of the visible pane; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #2f6b4f with white offset. Respect prefers-reduced-motion (no FLIP, toast or drawer transitions). Invented names and notes only.
