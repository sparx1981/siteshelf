Canvas & base: Dark slate workshop page #16181c with a soft lamp glow (radial #3a3a44 at 30%) and a calculator body #20242b (26px radius, 1px #343a46 border, deep shadow, brushed top plate). Key colours: digits #2c313b with #f1f3f7 text, operators #3a2f1c with brass #e8b04a text, functions #263341 with #9cc8ff text, equals brass gradient (#f0c262 to #d9982f, dark text #2b1a00), danger/clear #4a2326 with #ffb3ad. Display panel #0e1013 with brass digits #ffd37a (12:1) and dim secondary #8c93a3 (5.8:1). History tape #1b1e24. Invented calculator brand "Slideway".

Typography: "DM Mono" 400/500 for the display, keys and tape (display 40px, keys 18px); "Space Grotesk" 500/700 for labels and headings.

Layout: Header with eyebrow "Slideway", headline "A calculator that shows its working." and a line. Two columns: the calculator (max 420px) and a history tape (width 300px, a scrolling list of previous calculations with timestamps and results, with Clear and Copy buttons). Calculator: display with the expression line (small, scrolls horizontally inside its box), the live result (large), mode badges (DEG/RAD, M for memory in use); a key grid of 6 columns by 7 rows: Row 1: Deg/Rad, MC, MR, M+, M-, Clear (AC). Row 2: sin, cos, tan, ln, log, backspace. Row 3: x², sqrt, x^y, (, ), %. Row 4: 7 8 9 ÷ n!, pi. Row 5: 4 5 6 × 1/x, e. Row 6: 1 2 3 − +/-, Ans. Row 7: 0 (double width), . , + and equals (double width). All buttons have text labels and aria-labels for symbols.

Interaction: Pressing keys builds an expression; the live result updates as soon as the expression is valid (shown dimmed until equals commits it). Evaluation uses a hand-written tokenizer and shunting-yard parser (no eval): numbers, + - × ÷ ^, unary minus, percent, factorial, parentheses, constants pi and e, functions sin cos tan ln log sqrt with degree or radian mode, and Ans (the last result). Division by zero, domain errors and unbalanced brackets show a clear inline message ("Cannot divide by zero") without crashing, and 10 significant digits formatting with exponent notation for very large or small values. Equals appends the entry to the history tape (stored in localStorage with try/catch, last 30) and the result becomes Ans; clicking a tape entry loads its expression, clicking its result inserts that number. Memory: M+ adds the current result, M- subtracts, MR recalls, MC clears; the M badge lights while memory is non-zero. Keyboard: digits, + - * / ^ ( ) . % ! and Enter or = to evaluate, Backspace deletes, Escape clears, p for pi, r for sqrt, s c t for functions; focus stays on the calculator region (role="application" aria-label) and keys pressed light up the matching on-screen key briefly. Results announce via a polite live region.

Responsive: Under 860px the tape moves below the calculator (collapsible with a Show history button); keys keep a minimum 48px size, font 16px under 400px; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #ffd37a outline offset 3px with dark inner ring. Never use eval or Function. Respect prefers-reduced-motion (no key flash easing or tape slide). Invented names only.
