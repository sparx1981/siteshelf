Canvas & base: A dark desk-mat page #14161c with a faint grid and a soft lamp glow (radial #3a3f55 at 30%, top-left). Keyboard plate #1d2029 with 1px #2d3140 border, 24px radius and an inset shadow. Three keycap sets switchable by radios: Retro (beige #d8d1be top, #b6ae96 sides, charcoal legends #2a2a2a, orange accent keys #e0662f), Neon (black #101216 caps with cyan #19e6ff and magenta #ff3ea5 legends and glows) and Paper (white #f3f3f0 caps, #cfcfc8 sides, ink legends, one blue accent key #3a6df0). Text on the page #e8eaf2 (14:1). Invented keyboard maker "Clackworks".

Typography: "Space Grotesk" 600/700 for headings and key legends (18 to 22px); "JetBrains Mono" 400/500 for the readout and small labels (14px).

Layout: Header with eyebrow "Clackworks", headline "Keys with real weight." and a line. A keyboard plate holding two rows: Row 1 letter keys Q W E R T Y U I O P; Row 2 A S D F G H J K L and a wide Enter key; Row 3 a wide Shift, Z X C V B N M, comma, full stop; Row 4 a very wide Space bar with a small legend "space". Each key is 64px square (Space 400px, Enter 110px, Shift 110px). Every keycap is built from layers: a bottom shadow, a darker side block (translateY 8px) and a top face with a slight concave gradient and the legend, so the cap reads as 3D. Above the plate a readout area (monospace, 2 lines, blinking caret) shows typed characters and a counter "Keys pressed: 0". Below, theme radios and a "Clear" button.

Interaction: Pressing a key by pointer (pointerdown) sinks the top face 6px down (transition 60ms) and releases on pointerup or leave (120ms spring); pressing the matching physical keyboard key (event.code) does the same, with the key held while the physical key is held and repeats ignored. Each press appends the character to the readout (Space adds a space, Enter a new line, Shift toggles capitals which show on the legends, Backspace key on the physical keyboard removes a char and visibly nudges the Enter key). Keys are buttons with aria-label of the letter name (for example "Q") and aria-hidden legends; the readout is role="log" aria-live="off" with a visually hidden announcement of each word completed. Tab moves through keys in reading order; Enter or Space on a focused key presses it (key events handled so native clicks do not double-type). No sound. Themes change CSS variables live over 300ms.

Responsive: Under 900px the keyboard scales via a CSS variable --u (key unit) down to 30px at 390px width (rows stay intact, the page never scrolls horizontally); the readout and header stack; legend sizes scale with --u.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #ffb020 outline offset 3px on keys. Respect prefers-reduced-motion (key travel is instant, no spring, no caret blink). Invented names only.
