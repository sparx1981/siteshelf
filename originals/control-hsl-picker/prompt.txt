Canvas & base: Light studio page #f4f2ee with a white tool card (#ffffff, 1px #e3dfd6 border, 28px radius, soft shadow). Ink #1c1a17 (16:1), secondary #5f5a50 (6.3:1). The tool adopts the chosen colour for its accent (focus rings stay a fixed #1c1a17 with white offset for reliable contrast). Pass badges use #0f7a52 on #dff5ea, fail badges #b3261e on #fde8e6. Invented colour tool "Huebox".

Typography: "Bricolage Grotesque" 600/700/800 for headings and the large colour name (headline clamp 34px to 56px); "JetBrains Mono" 400/500 for colour values (15px); "Inter" 400/500 for labels (14 to 15px).

Layout: Header with eyebrow "Huebox", headline "Find a colour you can stand behind." and a line. A two-column card: left a 300px picker: an outer hue ring (conic-gradient of all hues, 300px diameter, 36px thick, cut with a radial mask) containing a 150px saturation/value square (background: white-to-hue horizontally and transparent-to-black vertically, 10px radius), each with a draggable circular handle (white ring with the current colour inside); right the info column: a large swatch (120px tall, 20px radius, with the colour name guess such as "Warm coral" computed from hue bands), three copyable value rows (HEX, RGB, HSL, each with a Copy button), numeric inputs for H (0-360), S (0-100), L (0-100), a contrast section ("On white 4.8:1 AA pass, AAA fail", "On black 4.4:1 ...", plus a live sample "Aa" text on and by the colour), and a harmony row of five generated swatches (Complementary, Analogous, Triad, Split, Tint ramp tabs) that can be clicked to adopt that colour.

Interaction: Dragging the ring handle changes hue (angle from centre), dragging in the square changes saturation and value (HSV internally, converted for display to HSL); handles use pointer capture with touch-action none. Keyboard: the ring is role="slider" (0 to 359, aria-valuetext "Hue 12 degrees, red-orange") with Left/Down -1, Right/Up +1, Shift 10, Home 0, End 359; the square is a 2D control exposed as two sliders (role="slider" saturation and role="slider" value) or a single focusable region with aria-roledescription "2D colour area" and arrow keys moving S and V by 1 (Shift 10) with aria-valuetext "Saturation 80 percent, brightness 90 percent". The numeric inputs update the picker two-way. Copy buttons use the clipboard API with try/catch and a fallback textarea select, showing "Copied" for 1.4s and a live-region announcement. The contrast badges recompute with WCAG relative luminance; badges say Pass or Fail in text (not colour alone). A "Random" button picks a pleasant colour, and recent colours (last 8) are kept as chips (localStorage in try/catch).

Responsive: Under 760px the card stacks (picker centred at min(300px, 86vw), info below); no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #1c1a17 outline with a white inner ring on handles, inputs and buttons. Respect prefers-reduced-motion (no handle easing or swatch transitions). Invented names only.
