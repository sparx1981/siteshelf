Canvas & base: Calm legal-paper page #eef0f4 with a white document card (#ffffff, 1px #d9dde6 border, 20px radius, soft shadow) showing a short invented agreement. Ink #14213d (15:1), secondary #56627a (6.3:1). The signature area is a framed field with a baseline: background #fbfcfe, 1.5px dashed #aab4c8 border, an "X" and a 1px baseline #c3cbdb about 70% down, and a "Sign above the line" hint. Pen colours: Ink black #14213d, Blue #1f4fd1, Green #0e7a5a. Accent #1f4fd1 for primary buttons (white text 6.9:1). Invented e-sign tool "Inkwell Sign".

Typography: "Newsreader" 500/600 for the document heading and clause text (17px); "Inter" 400/500/600 for UI (14 to 15px); typed signatures use "Caveat" 700, "Shadows Into Light" 400 and "Kalam" 400 (48px).

Layout: A two-part page. Left: the document card titled "Studio Hire Agreement" with three short numbered clauses and a party block ("Hirer: Marlow & Pine Ltd, 12 Orchard Row"), plus a fine-print date. Right (or below): a signing panel with tabs "Draw" and "Type", a signature field 100% by 200px, controls row (Pen colour radio swatches, Thickness slider 1.5 to 6 px, Undo, Clear), a typed tab with a name input and three style radio cards previewing the name in each script font, a live preview thumbnail of the final signature (PNG data URL) with "Download PNG" link, a checkbox "I agree this is my legal signature" and an "Accept and sign" button disabled (aria-disabled) until a signature exists and the box is checked, with an inline error message explaining what is missing when pressed too early. After signing, the panel shows a "Signed" confirmation with timestamp and the signature image.

Interaction: Drawing uses pointer events with setPointerCapture and touch-action:none on the canvas, smoothing strokes by quadratic curves through midpoints, variable line width from pointer speed (thinner when faster) between 60% and 110% of the chosen thickness, and a devicePixelRatio-scaled canvas that is re-rendered from stored strokes on resize. Undo removes the last stroke; Clear removes all (both announce via a polite live region). The Type tab renders the typed name onto the same canvas (centred on the baseline) in the chosen style so the output path is identical. A toggled keyboard-accessible alternative exists for people who cannot draw: the Type tab is fully keyboard operable (tablist with arrow keys, radio cards with arrow keys). The canvas itself is role="img" with aria-label "Signature drawing area. Use the Type tab if you cannot draw." The preview thumbnail updates on stroke end. Escape in the drawing area cancels the current stroke. Nothing is uploaded; all state stays local.

Responsive: Under 900px the document card sits above the signing panel; the canvas height becomes 170px; controls wrap; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #1f4fd1 offset 3px. Error messages are text (not colour only) and associated through aria-describedby. Respect prefers-reduced-motion (no pen cursor animation or confirmation transitions). Invented names only.
