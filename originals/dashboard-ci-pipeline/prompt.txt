Canvas & base: Dark developer UI #0d1117 with panels #151b23 (1px #283241 border, radius 12px). Text #e6edf3, secondary #8b98a9 (6.8:1). Status colours with icons and text: Passed #3fb950 (check), Failed #f85149 (cross), Running #58a6ff (spinner), Queued #8b98a9 (clock), Skipped #6e7681 (dash), Flaky #d29922 (warning). Invented repository "northwind/web" and CI product "Pipewise".

Typography: "Inter" 400/500/600/700 for UI at 14px (headings 18px 600); "JetBrains Mono" 400/500 for branch names, commit hashes, durations and logs at 12.5px.

Layout: Top bar with wordmark "pipewise", repo breadcrumb "northwind / web", branch select (main, release/4.2, fix/cart-total) and a "Run pipeline" primary button. Row 1: a run history strip of the last 14 runs as small pills (run number #2841 to #2828, coloured status icon, duration) that act as a listbox; the selected run is outlined. Row 2: run header (commit message "Fix rounding in cart total", author initials, hash a1b2c3d, branch, started time, total duration, status badge). Main panel "Pipeline": a left-to-right graph of stages in columns: Checkout, Install, Verify (three parallel jobs: Lint, Types, Unit tests), Build, End-to-end (two parallel jobs: Chrome, Mobile), Deploy preview. Each job is a rounded card with status icon, name and duration; connector lines (SVG paths) link stages; running jobs show a progress bar. Selecting a job opens a log panel below with 12 lines of invented log output in mono with coloured keywords and a "Copy log" button. Right/below panel "Flaky tests": a table (test name, failure rate %, last seen, impact) with buttons Rerun and Quarantine per row; Quarantine moves the row to a "Quarantined (2)" collapsed list with an Undo; a banner shows total CI minutes saved.

Interaction: Run pipeline starts a simulated run: stages progress in order over about 8 seconds (Queued, Running with progress bars, Passed), parallel jobs finishing at different times, and one E2E job occasionally fails then auto-retries once and passes; the header updates live and the new run is added to the history strip. Switching runs changes statuses (some historical runs have a failed Types job or a skipped Deploy). Keyboard: history is a roving-tabindex listbox, job cards are buttons, and Enter selects.

Responsive: Under 1000px the graph scrolls horizontally inside its own container with min-width 760px; flaky table scrolls; no horizontal scroll of the page at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Status always has icon and word; log region role=log; visible focus 3px #58a6ff. Respect prefers-reduced-motion (no spinner rotation or progress easing; static icons). Invented names only.
