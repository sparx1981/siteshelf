Canvas & base: Soft paper page #f8f5ee with white panels (1px #e6dfce border, radius 14px), ink #22201a, secondary #66604f (5.9:1), school green #1f6b47, ruler blue #2a5fc7, highlight yellow #fff2a8 for edited cells, grade colours with text letters: A #2f9e5a, B #7bb342, C #e0b030, D #e07a2f, F #d1383a (dark text on C). Invented class "Year 9 Science, Mrs. Adeyemi" at "Larchwood School".

Typography: "Newsreader" 600 for the title (30px); "Inter" 400/500/600 for the grid at 14px; "DM Mono" 400 for numbers in cells (13px, tabular).

Layout: Top bar with class title, term chip ("Autumn term"), search students field and an "Export CSV" button (toast only). Left/main: a grid table with sticky header and sticky first column: 14 students (invented names) by 8 assessments grouped in three weighted categories (Homework 20%: HW1, HW2, HW3; Quizzes 30%: Q1, Q2, Q3; Tests 50%: Mid-term, End-of-unit). Each cell is an editable number (0 to 100, one decimal allowed) with the cell background tinted by grade band; empty cells show a dash and count as missing. Right columns: Weighted total (%) with grade letter pill and a mini bar, and Trend arrow (up, down, steady) vs the previous term. Footer rows: Class average per assessment, highest, lowest. Right panel: a grade distribution bar chart (A to F counts) that updates live, class average ring, and an "At risk" list of students below 55% or with 2 or more missing marks, each with a one-click "Add note" chip that toggles a flag. A weights editor (three number inputs that must sum to 100, with a validation message and the Apply button disabled otherwise) recalculates all totals.

Interaction: Cells are inputs supporting Arrow keys (up, down, left, right move focus), Enter (commit and move down), Escape (revert), Tab; typing invalid values (above 100, below 0, letters) shows a red outline and message "Enter 0 to 100" and reverts on blur. On commit the cell flashes yellow for 600ms and dependent totals, ranking, chart and at-risk list update immediately. Column header buttons sort students by that assessment or total (aria-sort). A Show missing toggle highlights empty cells in pink.

Responsive: The grid scrolls inside its own container with sticky first column; the side panel moves below under 1100px; no horizontal scroll of the page at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Grade conveyed by letter and number as well as colour; aria-live for updated class average; visible focus 3px #2a5fc7. Respect prefers-reduced-motion (no flash). Invented names only.
