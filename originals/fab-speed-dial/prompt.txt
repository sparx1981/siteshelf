Canvas & base: A phone-like app stage on #eef0f6 with a scrollable notes list in a 420px card (white surface, 28px radius), ink #151826, secondary #667085, accent violet #6c4bf4, accent pink #f43f8e, accent teal #14b8a6, accent amber #f59e0b. Invented app "Jotter".

Typography: "Outfit" (400,500,600,700) at 15px.

Layout: A centred app card (420×760px max) with a header ("All notes", search icon), a scrollable list of 14 note rows, and demo selector tabs above the card (Speed dial, Extended FAB, Morph to sheet, Mini cluster) that swap the active FAB pattern in the card. The FAB sits bottom-right inside the card.

Interaction: 1) Speed dial: main FAB rotates its plus into a cross, a scrim dims the list, and four mini FABs (Checklist, Photo, Voice, Text) fan upward with staggered delays and visible text labels; Escape, scrim click or selecting an action closes; focus moves to the first action and returns on close; Arrow keys move among actions. 2) Extended FAB ("New note" with icon) shrinks to icon-only when scrolling down and expands when scrolling up, via class toggles with width transition. 3) Morph: the FAB expands into a bottom sheet (new note form with title, body, colour dots, Save/Cancel) using animated width/height/radius; Save adds a note to the top of the list. 4) Mini cluster: three stacked small FABs (Pin, Share, Archive) with tooltips on hover/focus, toggling pressed states. Selecting any action shows a toast "Checklist created" etc. Announce open/close state.

Responsive: Card becomes full viewport width below 460px; no overflow at 390px.

Rules: Single HTML file with a Google Fonts link, inline CSS and JS, no libraries or external images. Add [hidden]{display:none!important}. Visible focus, aria-expanded/aria-haspopup, respect prefers-reduced-motion, invented names only.
