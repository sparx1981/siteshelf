Canvas & base: Near-black page #0b0f0d for an invented developer-tools company "Kernel & Cog". The footer is a terminal window card: #0f1512 body, 1px #23332b border, 14px radius, a 38px title bar #16201b with three small coloured dots (decorative) and the title "visitor@kernelcog: ~". Phosphor green #5df2a0 for the prompt and output, soft white #d8e6dd for normal text (11:1), muted #7f968a for hints (5.3:1), amber #ffc561 for warnings, link cyan #7fd6ff. A faint scanline overlay (repeating-linear-gradient 3px at 4% opacity) and a soft inner glow. A theme command switches phosphor between green, amber (#ffb454) and ice (#8fd1ff).

Typography: "JetBrains Mono" 400/500/700 for the whole terminal (15px, 1.65 line height); "Space Grotesk" 500/700 for the page headline and the plain-links bar (clamp 36px to 64px headline).

Layout: A short hero above the footer (headline "Tools that stay out of your way.", one paragraph, two buttons) so the footer appears in the first viewport. The footer terminal is max 980px wide, 360px tall output area with its own scroll, then the prompt line "visitor@kernelcog:~$" followed by a real text input with a block cursor styled caret. Below the terminal a line of clickable command chips (help, ls, cd product, cd company, theme, clear) and a plain footer bar with real links (Docs, Pricing, Changelog, Status, Privacy, Terms, Security) and "© Kernel & Cog, hello@kernelcog.example.com".

Interaction: On load a greeting types out at about 16ms per character ("Welcome to Kernel & Cog. Type help, or press a chip below.") followed by a blinking cursor. Commands: help lists commands; ls lists the four sections (product, docs, company, legal) as directories, or within a directory lists its links as real <a> elements; cd <section> changes the prompt path (cd .. and cd with no argument go home); open <link> prints "Opening …" and scrolls to top or shows a toast (no navigation); whoami, date, echo, history, theme [green|amber|ice], clear, sudo (prints a polite refusal), and unknown commands print "command not found" with a closest-match suggestion. ArrowUp/ArrowDown walk history; Tab completes commands and directory names; Ctrl+L clears; Enter runs. Clicking a chip types its command into the input at 25ms per character then runs it. The output region is role="log" aria-live="polite" with output preserved; the input has an accessible label "Terminal command". Clicking anywhere in the terminal focuses the input. Typed greeting and chip typing are skipped (instant) when reduced motion is preferred.

Responsive: Under 640px the font size is 13px, the title bar dots are hidden, chips wrap, the output height is 300px and the plain-links bar stacks; no horizontal scroll at 390px (long lines wrap with overflow-wrap:anywhere).

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Every link is also reachable without the terminal (the plain bar). Visible focus 3px outline in the phosphor colour with black offset. Respect prefers-reduced-motion (no typing animation, no cursor blink). Invented names only.
