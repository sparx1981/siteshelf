Canvas & base: Cool grey app page #eceff4, white profile card with 1px #d9dfe9 border, radius 22px and soft shadow, ink #172033, secondary #5a6780 (6:1), indigo #4f46e5 accent, success #17a673, error #d03a3a, edit-state field background #f2f4ff. Invented user "Ada Okonkwo-Reyes", product designer at "Brightfield".

Typography: "Space Grotesk" 600/700 for the name and section titles (name 32px); "Inter" 400/500/600 for body 16px and labels (13px uppercase .08em tracking). 

Layout: Centred card max-width 720px. Top banner strip in indigo gradient (80px) with a 96px avatar circle (initials "AO" on #ffd1dc, 4px white ring) overlapping it. Header row: name (editable), role line (editable) and a "Profile 86% complete" pill. Below, a definition-style list of fields each on its own row with a label on the left (140px) and value on the right: Full name, Job title, Email, Phone, Location, Website, Bio (multi-line, 200 character limit with counter), Pronouns (select: she/her, he/him, they/them, Prefer not to say). Each row shows the value as text with a pencil icon button that appears on hover or focus-within (always visible on touch); activating (click, Enter or the pencil) swaps the value for an input with Save (check) and Cancel (x) icon buttons and the row gets a tinted background and an indigo left border.

Interaction: Enter saves (Shift+Enter for new line in Bio), Escape cancels and restores the previous value, Tab moves to the Save button then Cancel. Validation on save: name 2+ characters, email format, phone digits 7 to 15 with optional + and spaces, website must start with http, bio max 200; errors show beneath the input with aria-invalid and keep the row in edit mode. After a successful save the value text flashes a light green highlight for 800ms and a toast "Email updated" appears with an Undo button (5 second countdown bar); Undo restores the previous value and announces it. Only one row edits at a time: starting another row saves nothing and cancels the first. The completeness percentage recalculates from non-empty fields. Empty values show a muted "Add phone number" prompt styled as a dashed button.

Responsive: Under 560px label sits above value and the pencil is always visible; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Edit buttons labelled "Edit email" etc, toast is role=status, visible focus 3px #4f46e5. Respect prefers-reduced-motion (no highlight flash or countdown animation). Invented names; example addresses only.
