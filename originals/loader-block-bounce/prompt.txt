Canvas & base: Sunny toy-shop page #fff3d6 with a pattern of faint dots (radial #f0d9a0 2px at 28px) and a floor line at the bottom of the stage (a 10px rounded plank #d9a65c). Blocks are rounded squares (22% radius) with a top highlight and soft inner shadow in four colour sets: Primary (#ff5a4d, #ffc531, #2f9bff, #3fcf8e, #8a5cff), Pastel (#ffb3c7, #ffe0a3, #b6e3ff, #c6f0d1, #d8c6ff) and Mono (graded greys #2b2b2b to #bdbdbd) and Neon (#ff2d95, #ffe600, #00e5ff, #7dff3a, #b455ff, dark base). Ink #2a2118 (14:1). Invented toy brand "Tumble & Toss".

Typography: "Baloo 2" 600/700/800 for headings and the loading message (headline clamp 38px to 68px, message 26px); "Nunito" 400/700 for controls (15 to 16px).

Layout: Header with eyebrow "Tumble & Toss", headline "Please bounce responsibly." and a line. A stage (max 760px, 300px tall, rounded 24px, background #fffaf0 with a 1px #f0dcaa border) where five blocks (size 56px by default) sit in a row on the plank, each with a tiny cartoon face (two dots and a curved mouth drawn in SVG) that blinks. Under each block a soft elliptical shadow. Below the stage: a loading message that cycles ("Stacking the shelves...", "Counting the marbles...", "Polishing the blocks...", "Nearly there...") with an animated ellipsis, and a mini counter "Loaded 3 of 5 toys". Controls: Colour set radio chips, Size slider (36px to 84px), Count select (3 to 7), Speed slider (0.6x to 1.8x) and a Pause button; clicking or pressing a block makes it jump with an extra high bounce.

Interaction: Blocks bounce in a travelling wave with 120ms phase offsets using CSS keyframes on the block wrapper (translateY up to 120px with ease-out going up, ease-in coming down), while an inner element applies squash on landing (scaleY .72 / scaleX 1.22 for 90ms), stretch mid-air (scaleY 1.18 / scaleX .9) and a tiny rotation; shadows shrink and fade at the apex. Faces blink every 3 to 5 seconds with staggered timers and the mouth opens at the apex. Pressing a block (pointer or Enter/Space on the focused block) triggers an extra high bounce animation once and plays a small "star" burst of 6 SVG sparkles; blocks are focusable buttons with aria-label "Bounce block 3". The stage is role="progressbar" aria-label "Loading toys" with aria-valuenow cycling (updated every 20%); the message changes every 1.4s and is aria-hidden to avoid chatter; a single polite announcement "Toys loaded" appears each time the cycle completes (about every 7s). Controls update CSS variables live; the Pause button (aria-pressed) pauses all animations.

Responsive: Under 560px blocks scale with the stage (max size 44px), the stage height becomes 240px, the controls wrap; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #2a2118 outline with a white inner ring. Respect prefers-reduced-motion (blocks do a gentle 8px hop at one third speed with no squash, no sparkles; Speed control hidden). Invented names only.
