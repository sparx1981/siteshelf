Canvas & base: Quiet slate page #0f1524 with a very soft starfield (tiny radial dots at 8% opacity) and six tiles in a grid (#172036, 1px #263250 borders, 20px radius, 200px tall). Dot colours are driven by a palette setting: Sky (#6ec7ff and #b7e4ff), Mint (#4de2b0 and #b3f5df), Blush (#ff8fb3 and #ffd0e0). Text #e9eefc (14:1), secondary #9aa8c7 (6.9:1). Invented UI kit "Calmloop".

Typography: "Outfit" 500/600/700 for headings and tile labels (headline clamp 34px to 56px); "Inter" 400/500 for captions and controls (14 to 15px).

Layout: Header with eyebrow "Calmloop", headline "Loaders that don't shout." and a line. Controls row: Palette radio chips (Sky, Mint, Blush), Speed slider (0.5x to 2x, default 1x), Size slider (24px to 64px, default 40px) and a Pause or Play toggle (aria-pressed). A 3-column grid of six tiles, each holding a CSS-only animated loader and a caption with its name and when to use it: (1) Single Orbit: one dot circling a faint ring; (2) Comet Trail: a lead dot with five fading followers; (3) Planets: three dots on rings of different radii with different periods; (4) Binary: two dots orbiting each other around a moving centre; (5) Pendulum: a dot swinging along a 120-degree arc with easing at the ends; (6) Breathing Ring: eight dots on a circle expanding and contracting in a wave. All sizes use CSS variables (--s, --speed, --c1, --c2).

Interaction: Palette, Speed and Size sliders update CSS variables live; the Pause toggle sets animation-play-state: paused on every loader (and the label changes to Play). Each tile is focusable (tabindex 0) so keyboard users can press Enter to pause that single loader (aria-pressed on the tile), with the tile showing a small pause badge. Loaders are decorative but the page offers one visually hidden live status "Loading" per tile through role="status" aria-label ("Single orbit loader, loading"). Tiles brighten slightly on hover and show the name and CSS custom-property snippet for that loader in the caption.

Responsive: 3 columns above 900px, 2 above 560px, 1 below; the controls wrap; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #ffffff outline offset 3px. Animations use transform and opacity only. Respect prefers-reduced-motion (loaders show a static arrangement with a slow 6-second opacity pulse; the Speed control is hidden). Invented names only.
