Canvas & base: Full-viewport boot screen #0a0d12 with a faint scanline overlay and a subtle vignette; text in warm paper-white #e9e4d8 (13:1) with status tags in green #7be39a, amber #ffc766 and cyan #7ad7ff, dim text #8d8a80 (5.6:1). When the boot completes the screen cross-fades (700ms) into a light app dashboard (#f4f1ea, white cards, ink #1a1815) for an invented project tool "Quillboard". A small floating control cluster (Skip, Replay, Speed) sits bottom-right on both screens.

Typography: "Space Mono" 400/700 for the entire boot log (15px, 1.7 line height, letter-spacing .02em); "Bricolage Grotesque" 600/700/800 for the dashboard headings and "Inter" 400/500 for dashboard body.

Layout: Boot screen: a centred 720px column. First a large ASCII-like logotype built from text ("QUILLBOARD" in 7 lines of block characters, or a simple bold wordmark with a quill glyph in SVG), version line "v3.2.0 (build 4417)", then a log of 14 lines typed in sequence: "Initialising workspace...", "Mounting /projects [ OK ]", "Checking licence [ OK ]", "Loading boards (12) [ OK ]", "Warming search index... [ WAIT ]" turning into "[ OK ]", "Syncing 3 teammates [ OK ]", "Restoring last session [ OK ]", ending with "Ready." Each line has a time prefix [00.12s]. At the bottom a text progress bar "[#####-----] 52%" plus a percentage. Dashboard: a header with the Quillboard logo and search, three board cards (Launch plan, Reading list, Garden notes) with progress bars, and a "Today" list of four tasks.

Interaction: Lines type character by character (18ms per char, with a random 40 to 160ms pause between lines); status tags are inserted at the end of the line with a short flash; the caret is a blinking block that follows the active line; the progress bar updates per line. At completion "Ready." types, a 600ms hold, then the boot screen fades out and the dashboard fades in with cards rising in sequence (translateY 16px, 70ms stagger). Controls: Skip (jumps to the dashboard immediately), Replay (returns to the boot screen and restarts) and Speed (Slow, Normal, Fast, Instant) as a select; Escape or any key press during boot also offers skip via the button focus (the Skip button receives focus on load so keyboard users can skip). The boot log container is role="log" aria-live="off" with a single polite announcement at each 25% ("Loading, 50 percent") and "Ready" at completion; the dashboard is revealed to assistive tech (aria-hidden removed, focus moved to its main heading) when shown.

Responsive: Under 640px the logotype switches to a smaller wordmark, font-size 13px and the log wraps; the dashboard cards stack; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #7ad7ff outline offset 3px (on dashboard use #1a1815). Respect prefers-reduced-motion (the log appears fully at once with a short 200ms fade to the dashboard; no typing, caret blink or stagger). Invented names only.
