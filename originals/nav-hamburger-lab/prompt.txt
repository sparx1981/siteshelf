Canvas & base: Near-black graphite page #101216 with a soft radial glow of violet (#7c5cff at 14%) behind the demo stage. Panels #181b21 with 1px #2a2f38 borders and 20px radius. Text #eef0f4, secondary #9aa3b2 (6.9:1). Accent violet #8f74ff, second accent lime #c6f25a for the active state. Invented studio "Foldline Labs".

Typography: "Space Grotesk" 500/700 for headings and labels; "JetBrains Mono" 400/500 for the code-style values (13px).

Layout: Two columns on desktop. Left: a "Pick a morph" panel with six large selectable tiles (Classic X, Spin Plus, Arrow Back, Dots Grid, Squeeze, Wave Close), each tile showing its icon in a live toggle and its name; below, a speed slider (150ms to 900ms) and an "Easing" radio group (Snappy, Springy, Smooth). Right: a mock site frame (rounded 24px, 560px wide) with a top bar containing a logo "Foldline" and the currently chosen icon button, a hero text block, and a slide-in menu panel (right side, 300px) with five links and a close hint. All six icons are built from inline SVG lines or CSS bars, 28px, 2.5px strokes, and morph between closed and open state using transforms only (rotate, translate, scale, opacity, stroke-dashoffset).

Interaction: Clicking a tile selects that icon style, keeps the current open or closed state and plays a short preview toggle. The mock site's icon button toggles the menu; the same toggle drives the icon morph, so the icon animation always reflects aria-expanded. Opening the menu slides the panel in, dims the page with a scrim, makes the rest of the frame inert and traps focus; Escape and scrim click close it and return focus to the button. The speed slider updates a CSS custom property (--dur) live; easing radios set --ease (cubic-bezier values shown in a mono readout). Tiles are a radiogroup with roving arrow-key selection. A "Copy CSS" button copies a short CSS snippet for the chosen morph with try/catch around the clipboard and a visible "Copied" state.

Responsive: Under 900px the columns stack with the mock site first; tiles form a 2 by 3 grid; the frame is full width; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS/JS, no libraries or external images. [hidden]{display:none!important}. Icon buttons have aria-label "Open menu" or "Close menu" that updates with state; decorative SVG aria-hidden. Visible focus 3px #c6f25a with dark offset. Respect prefers-reduced-motion (morphs become instant, slide uses opacity only). Invented names only.
