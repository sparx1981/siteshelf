Build a single-page "Cron Explainer" tool for an invented operations-tools site, "Tickwell": type a five-field cron expression and get a plain-English sentence, a field-by-field breakdown, the next five run times (local or UTC) and a five-week calendar showing how many runs land on each day. Everything runs in the page.

Canvas & base: A warm "railway station at night" look. Page #17140f with a faint amber light pool near the top, panels #221d15 with a 1px #3d3424 border and 14px radius, ink #f6efe0 (14.9:1), secondary #c8bb9f (9.2:1), brass accent #e3b04b (dark text #2a2008 on it 8.9:1), signal green #7fd49a, alert red #ff8a7a. Subtle paper-grain overlay at 5% opacity. Invented brand "Tickwell" with a small clock-face logomark.

Typography: "Playfair Display" 700 for the title (clamp 30 to 54px) and the plain-English sentence (clamp 22 to 32px, italic for emphasis words); "Inter" 400/500/600 for UI at 14 to 15px; "IBM Plex Mono" 500 for the expression, fields and times (tabular numerals). Eyebrow 12px, 0.16em tracking, uppercase, brass.

Imagery & art direction: A painted banner (inline SVG using the scene library's city generator in a deep night palette, lit windows, a faint moon, light grain and vignette) sits behind the title, with a large illustrated station clock on the right: brass bezel, ivory dial, Roman-style tick marks, drop shadow, and hour and minute hands that point to the NEXT run time and sweep there with a 600ms ease whenever the expression changes (instant under reduced motion). Under the clock a small enamel plate reads "Next: Tue 09:00". A "ticket" card holds the expression in a perforated-edge frame like a train ticket. The calendar uses small painted dots, not plain squares. Media slots for real photography: optionally one 1600x500 night-station photograph for the banner.

Layout: Banner with eyebrow, title "Cron Explainer", short intro, the clock. Below, a ticket card containing the expression input (monospace, 28px, five fields shown as a spaced row with labels MIN HOUR DAY MONTH WEEKDAY beneath each token that follow the caret region), preset chips, a Local/UTC toggle and a Copy button. Then the sentence panel (large). Two columns above 960px: left a Breakdown table of five rows (field, token, meaning, allowed range) and the Next runs list (5 rows: weekday, date, time, relative "in 3h 12m"); right the calendar (5 weeks starting from this week's Monday, each day showing the run count as a number plus up to three dots, today ringed, runs-heavy days tinted).

Copy: Default expression "0 9 * * 1-5" -> "At 09:00 on Monday through Friday." Other sentences: "Every 15 minutes." "At 02:30 every day." "At 00:00 on day 1 of the month." "At 08:00 on day 1 of January, April, July and October." Errors: "Minute must be 0 to 59.", "Expected 5 fields, found 4.", "Unknown name 'FUNDAY' in weekday."

Interaction: Parse on input: five fields separated by whitespace (also accept @hourly, @daily, @weekly, @monthly, @yearly), each field supporting *, lists (a,b), ranges (a-b), steps (*/n, a-b/n, a/n), and names (JAN-DEC, SUN-SAT, 7 = Sunday). Validate with a message tied to the offending field (that token is outlined and aria-invalid on the input; role=alert message). Build explicit value sets per field. Day-of-month and weekday follow classic rules: if both are restricted a run happens when either matches; if only one is restricted that one applies. Next runs: iterate days from now, test month and day rules, then the sorted hours x minutes sets, collecting the first five times after the current minute, in local or UTC according to the toggle. Calendar: for each of 35 days compute matching and run count = hours x minutes. Sentence builder handles every, step, single, list and range forms for minute, hour, day, month and weekday, joining lists with commas and "and", and writes times as HH:MM when one minute and one or more hours are given. Presets (Every 15 minutes, Weekdays at 9, Nightly 02:30, First of month, Quarterly, Twice a day) fill the input. Hands: hour angle = (h mod 12) x 30 + m x 0.5, minute angle = m x 6. A polite live region announces the sentence after the user pauses typing (500ms). Copy uses the Clipboard API in try/catch. The last expression persists in localStorage inside try/catch.

Technique notes: Day iteration stops after 4 years if nothing matches (for example "0 0 31 2 *") and shows "No run in the next 4 years." Hand motion uses a transform-origin at the dial centre and a CSS transition on rotate; take the shortest path by accumulating angle deltas rather than resetting to 0.

Responsive: Under 960px the columns stack; the ticket fields wrap into a two-row grid; the calendar keeps 7 columns with 40px cells; the clock drops to 96px beside the title; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS and JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #f6efe0 outline with dark offset. Never rely on colour alone: counts are numbers and error text is written out. Respect prefers-reduced-motion. Invented names only.
