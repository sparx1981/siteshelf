Build a single-page "Gradient Generator" tool for an invented utility site, "Hue Bench": build multi-stop CSS gradients visually, see them on a realistic mock page, and copy clean CSS. Everything runs in the page.

Canvas & base: A calm dark workbench UI: page #12141c, panels #1b1f2b with a 1px #2c3244 border and 16px radius, text #eef1fa (15.2:1), secondary #a6aec8 (7.9:1), accent electric violet #8b7bff (white text 4.9:1 on it; use #5b4bd8 for filled buttons with white text 7.4:1), success mint #5de0a8. The preview area is a light-neutral stage #e9ecf3 with a faint checker pattern so transparent stops read clearly. Invented brand only.

Typography: "Space Grotesk" 600 for the title (clamp 28 to 44px) and panel headings; "Inter" 400/500/600 for UI at 14 to 15px; "JetBrains Mono" 500 for hex values, positions and the CSS output (tabular numerals). Eyebrow 12px, 0.16em tracking, uppercase, #8b7bff.

Imagery & art direction: The preview must show gradients in context, not as a flat swatch. Paint (inline SVG and CSS) a mock marketing hero inside a browser window frame (three traffic-light dots, a URL pill "example.com"): the live gradient fills the hero background with a large headline "Colour that moves", a sub line, two buttons, a floating glass card with a small chart and a soft shadow, plus a decorative grain overlay at 10% and subtle vignette. A second tile shows the same gradient on a phone-shaped card (rounded 36px, notch, status bar) with a login-style UI, and a third shows it as a text fill on a big word and as a border (gradient border on a pill button). A strip of 8 preset thumbnails (Sunset, Ocean, Aurora, Peach, Neon, Forest, Candy, Midnight) is drawn as small rounded swatches with names. The angle dial is a circular knob with tick marks and a glowing indicator. Media slots for real photography: none required; optionally a 1600x900 photograph that can replace the mock hero background to preview a gradient overlay on imagery.

Layout: Header with eyebrow "Hue Bench" and title "Gradient Generator". Two columns above 980px: left the preview stack (browser mock, phone card and the text and border sample row), right the control panels: Type (Linear, Radial, Conic) as a segmented control; Angle (a circular dial plus a number input 0 to 360, shown for linear and conic) or Position and shape for radial (Circle or Ellipse, centre at 9 position buttons); Stops (a gradient bar with draggable handles above a list of stop rows: colour swatch input, hex input, position input and slider, opacity slider, remove button; Add stop button), toggles Repeat and Smooth (interpolate in OKLCH when supported), Presets strip, Random and Reverse buttons, a Contrast panel (white and black sample text on the gradient's average colour with ratio and AA pass or fail), and an Output panel: the CSS in a code block with Copy button and a second line with the gradient in Tailwind arbitrary-value form.

Copy: Default gradient: linear 135 degrees from #ff6a88 (0%) through #ffb86c (45%) to #6a7bff (100%). Messages: "CSS copied." and "Added stop at 72%." Sample: headline "Colour that moves", body "Drag a handle, turn the dial, copy the code."

Interaction: The model is {type, angle, shape, pos, stops[{color, pos, alpha}], repeat, smooth}. Every change redraws the previews and regenerates the CSS immediately (using linear-gradient, radial-gradient or conic-gradient; repeating-* when Repeat is on; the "in oklch" interpolation hint when Smooth is on and CSS.supports allows it, otherwise omit). The gradient bar shows draggable handles (pointer events with setPointerCapture) that update stop positions with 1% snapping (hold Shift for 0.1%); clicking the bar adds a stop at that position with the interpolated colour; double-click or the Remove button deletes a stop (minimum 2). The dial is a role="slider" (aria-valuemin 0, aria-valuemax 360) controlled by dragging, arrow keys (1 degree, Shift 10), Home and End. Stop handles are focusable with arrow keys to nudge. Colour inputs use the native color input plus a hex text field with validation. Presets set the whole model; Random generates 2 to 4 stops in harmonious hues (HSL with random base hue and offsets 25 to 140 degrees, saturation 65 to 90, lightness 50 to 70). Contrast compares the gradient's average colour (mean of stops weighted by distance) with white and black text using the WCAG formula and reports ratios and AA large or normal pass. Copy uses the Clipboard API inside try/catch, and announces politely. The last gradient persists in localStorage inside try/catch. Keyboard: all controls reachable; a visually hidden description tells how to use the bar handles.

Responsive: Under 980px the panels stack under the previews, the preview browser mock scales to full width (aspect 16:10), the stop rows wrap into two lines; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS and JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #ffffff outline with a dark offset. Colours are always shown as text values as well as swatches. Respect prefers-reduced-motion (no transitions on the previews). Invented names only.
