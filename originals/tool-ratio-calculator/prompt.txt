Build a single-page "Aspect Ratio Calculator" tool for an invented photography-and-layout site, "Framewell": enter a width and height, lock a ratio, pick a preset, and see matching sizes, the CSS to reproduce the ratio, and a viewfinder preview that shows how a painted photograph crops to the chosen frame. Everything runs in the page.

Canvas & base: A "contact sheet" look. Page #efece6 with a faint film-sprocket pattern along the top edge, panels #fffdf9 with a 1px #d8d2c4 border and 14px radius, ink #1a1a1a (16.9:1), secondary #57534a (7.3:1), accent deep teal #0b6e6e (white text 6.1:1), vermilion #e4572e used only for crop marks and decorative accents (never as text on light), highlight tint #d9f0ee. Invented brand "Framewell" with a tiny viewfinder-corners logomark.

Typography: "Syne" 700 for the title (clamp 30 to 54px) and panel headings; "Inter" 400/500/600 for UI at 14 to 15px; "DM Mono" 500 for numbers and CSS (tabular numerals). Eyebrow 12px, 0.16em tracking, uppercase, teal.

Imagery & art direction: The preview is a camera viewfinder: a dark stage holding a painted coastal photograph (inline SVG from the scene library's landscape generator: a golden-hour headland, sea and layered clouds, grain and vignette), cropped live to the chosen ratio with preserveAspectRatio slice. The frame has vermilion corner brackets, a centre cross, optional rule-of-thirds lines and a small HUD ("1920 x 1080 · 16:9 · 2.07 MP"). The uncropped photograph is shown dimmed outside the frame so the cut-off area is visible, with a crop percentage readout ("12% of the width is cropped"). Each preset chip contains a tiny painted frame of its own ratio (a mini crop of the same photograph) so the ratios can be compared at a glance, like a strip of film. Media slots for real photography: one 1600x1000 landscape photograph replacing the painted one (alt text, object-fit cover).

Layout: Header (eyebrow "Framewell", title "Aspect Ratio Calculator", one-line intro). Two columns above 980px. Left: Calculator panel (Width and Height number fields with px suffix, a Lock ratio toggle button with aria-pressed, a Ratio field accepting 16:9, 16/9, 16 x 9 or 1.778, a Swap orientation button, nearest-ratio note), the Presets strip (10 chips: 16:9, 4:3, 3:2, 1:1, 4:5, 9:16, 21:9, 2:1, A-series 1:1.414, Golden 1.618:1) and the "Typical uses" line for the active ratio; below, the Sizes table (widths 320, 480, 640, 768, 1024, 1280, 1920, 2560, 3840 with computed heights and a per-row Use button) and the CSS panel (aspect-ratio rule, padding-top percentage fallback, and a Copy button). Right (sticky): the viewfinder stage (fixed 360px high, centred frame), toggles (Rule of thirds, Show uncropped photo) and the HUD readouts.

Copy: Defaults 1920 x 1080 = 16:9. Notes: "1366 x 768 is 683:384, closest common ratio 16:9 (0.1% off)." "Ratio unlocked: changing a side updates the ratio." Typical uses: 16:9 "Video, YouTube, laptop and TV screens"; 4:3 "Presentations, older monitors, iPad"; 3:2 "35mm photography, Surface devices"; 1:1 "Square posts and avatars"; 4:5 "Portrait social posts"; 9:16 "Stories, reels and phone video"; 21:9 "Ultrawide and cinematic"; 2:1 "Panoramas and wide banners"; 1:1.414 "A4 and other ISO paper"; 1.618:1 "Golden rectangle layouts". Errors: "Enter a ratio like 16:9 or 1.778." "Width must be a number above 0."

Interaction: With Lock on, editing Width sets Height = round(Width x rh / rw) and editing Height sets Width = round(Height x rw / rh); with Lock off, editing either side recalculates the ratio from the two numbers (reduced by greatest common divisor, with a nearest-preset note when the reduced form has large numbers). Ratio field: parse "a:b", "a/b", "a x b" or a decimal; on valid input keep Width and set Height. Presets set the ratio and keep Width. Swap exchanges Width and Height and inverts the ratio. The Sizes table recalculates from the ratio; Use sets Width. CSS output: "aspect-ratio: 16 / 9;" and "padding-top: 56.25%;" with the percentage to 4 decimals trimmed. The viewfinder sizes the frame to fit the 360px stage (landscape fills width, portrait fills height) using a ResizeObserver or resize handler; the crop percentage compares the frame ratio with the photograph's 1.6 ratio. All inputs validate inline with aria-invalid and role=alert messages; arrow keys step fields by 1 (Shift 10). Copy uses the Clipboard API in try/catch with a polite live-region message ("CSS copied."). Last values persist in localStorage inside try/catch.

Technique notes: Crop maths: if frameRatio > 1.6 the top and bottom are cut by 1 - 1.6 / frameRatio; otherwise left and right by 1 - frameRatio / 1.6. The dimmed uncropped photograph is the same SVG drawn behind at reduced opacity with the frame as a clipped, full-brightness copy (use a CSS clip-path inset computed from the crop, not a second DOM copy of ids: reuse the SVG once and apply an overlay of four dark rectangles).

Responsive: Under 980px the viewfinder moves above the calculator (not sticky, 280px high); the sizes table scrolls inside its own box; chips wrap; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS and JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #1a1a1a outline with white offset. Every number is shown as text. Respect prefers-reduced-motion (no frame transitions). Invented names only.
