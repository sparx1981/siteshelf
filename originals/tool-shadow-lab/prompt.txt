Build a single-page "Box Shadow Lab" tool for an invented utility site, "Depth Bench": design layered CSS box-shadows visually, preview them on a card, button or circle across different surfaces, and copy clean CSS. A "natural shadow" generator builds smooth multi-layer shadows from a single elevation value. Everything runs in the page.

Canvas & base: Light, airy workbench UI: page #f1f3f8, panels #ffffff with a 1px #dfe3ee border and 16px radius, ink #161a26 (16.4:1), secondary #586078 (6.2:1), accent indigo #4153d6 (white text 6.9:1), success green #1c7a52. The preview stage is a large rounded area whose surface can be switched: Paper (#f7f4ee with a fine grain), Light (#eef1f7), Dark (#14172a), Colour (a soft gradient from #bfe3ff to #ffd9f0) and Wood (painted walnut). Invented brand only.

Typography: "Sora" 600 for the title (clamp 28 to 44px) and panel headings; "Inter" 400/500/600 for UI at 14 to 15px; "IBM Plex Mono" 500 for numeric values and the CSS output (tabular numerals). Eyebrow 12px, 0.16em tracking, uppercase, indigo.

Imagery & art direction: The preview is a styled still life, not a bare box. On the stage the subject sits in a composed scene (inline SVG and CSS): a product card with a painted illustration (a ceramic mug render with soft contact shadow, a title "Stoneware Mug", a price and an Add button), flanked by two smaller cards at lower elevation (a plant in a pot, a notebook) so layering and depth relationships are visible; a rounded button and a circular avatar sample below. The surface changes the lighting: Paper shows fibre grain; Dark shows rim light on edges; Wood shows grain lines and a soft lamp glow. A small "light direction" indicator (a sun glyph on a ring) rotates to match the dominant shadow offset, and a faint floor reflection appears for elevated cards. A strip of eight preset thumbnails (Soft, Layered, Crisp, Neumorphic, Glow, Hard, Floating, Inset) shows each effect on a tiny card. Media slots for real photography: none required; optionally a 1600x900 desk photograph for the Wood surface.

Layout: Header with eyebrow "Depth Bench" and title "Box Shadow Lab". Two columns above 980px: left the stage (aspect 4:3, sticky) with surface chips above it and shape chips (Card, Button, Circle) and Background colour of the subject (a colour input); right the controls: Natural generator (Elevation 1 to 12 slider, Softness 0 to 100, Colour input with Opacity slider, Light angle slider 0 to 360 degrees, Layers 2 to 8, a Generate button) then the layer list: each layer row shows x, y, blur, spread number inputs with range sliders (x and y -100 to 100, blur 0 to 200, spread -50 to 100), colour and opacity, an Inset checkbox, a Visible eye toggle, Duplicate and Remove buttons, and drag handles or up and down buttons for order; Add layer button; Radius slider (0 to 60 px) and Presets strip; Output panel with the CSS box-shadow value in a code block (one line per layer) and Copy, plus a second line "Tailwind arbitrary value".

Copy: Default: three layers "0 1px 2px rgba(20,25,50,.10), 0 4px 8px rgba(20,25,50,.10), 0 12px 24px rgba(20,25,50,.12)". Messages: "CSS copied.", "Generated 5 layers at elevation 6." and "Layer 2 hidden."

Interaction: Model: an array of layers {x, y, blur, spread, color, alpha, inset, visible} plus radius, surface, shape and subject colour. Every control updates the preview's box-shadow immediately and rewrites the CSS (rgba values with 2 decimals, omitted spread when 0, "inset" prefix when set). Numeric inputs and sliders stay in sync; arrow keys adjust range sliders natively. The natural generator creates N layers where each layer i (0 to N-1) has t = (i+1)/N, offsetY = elevation x t^1.8 x 2, offsetX = offsetY x cos(angle) factor (light angle controls the x/y split), blur = elevation x t^1.6 x 4 x softnessFactor, spread = -elevation x 0.2 x (1 - t), alpha = baseAlpha x (1 - t x 0.55) / N-weighted so total darkness stays plausible. Presets replace the layer list. Layers can be reordered (up and down buttons and Alt+Arrow keys on the layer row), hidden, duplicated and removed (minimum 1). The light-direction indicator rotates based on the first visible non-inset layer's offset angle. Output uses a monospace code block with a Copy button (Clipboard API inside try/catch), polite announcement. State persists in localStorage inside try/catch. Keyboard: all controls reachable; the layer list is a group with clear labels ("Layer 2, offset 0 8, blur 16").

Responsive: Under 980px the stage moves above the controls (aspect 16:10, not sticky), layer rows wrap into two lines and sliders go full width; no horizontal scroll at 390px.

Rules: Single HTML file, Google Fonts link, inline CSS and JS, no libraries or external images. [hidden]{display:none!important}. Visible focus 3px #161a26 outline with white offset (on the dark stage use white with dark offset). Values are always shown as numbers, never only visually. Respect prefers-reduced-motion (no transitions on the preview). Invented names only.
