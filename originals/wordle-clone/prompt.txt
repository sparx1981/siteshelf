Canvas & base: A clean game screen on #ffffff (dark mode #121213 via prefers-color-scheme plus a manual toggle). Tile states: empty border #d3d6da, filled border #878a8c, correct #538d4e, present #b59f3b, absent #787c7e, all with white letters. A high-contrast option swaps correct to orange #f5793a and present to blue #85c0f9. Invented name "Letterlane".

Typography: "Clear Sans"-style fallback is not available, so use "Rubik" (500, 700) for tiles and keys (uppercase, tabular) and "Libre Franklin" (400, 600, 800) for the interface. Title 30px 800 with letter-spacing .02em.

Layout: Centred column max 500px. Header with title, three icon buttons (How to play, Stats, Settings) and a thin divider. A 6-row by 5-column grid of square tiles (gap 5px, tile size clamp(48px, 13vw, 62px)), then a three-row on-screen QWERTY keyboard with wide Enter and Delete keys. Keys take on the best-known state colour per letter.

Interaction: Choose the answer from an embedded list of about 250 common five-letter words using today's date as a seed, so everyone sees the same word each day. Type with the physical keyboard or tap keys; Backspace deletes; Enter submits. Incomplete rows shake with a "Not enough letters" toast; a row is accepted if it contains five letters. Accepted rows reveal tile by tile with a 3D flip (staggered 250ms); duplicate letters are scored correctly (greens first, then yellows limited by remaining counts). Win bounces the row and shows a message ("Splendid", "Great", "Nice", etc. by attempt); loss reveals the word. A Stats dialog (native dialog) shows played, win %, streak, max streak and a six-bar guess distribution, saved in localStorage inside try/catch. Share copies a result grid of emoji squares with the attempt count. Settings: Hard mode (revealed hints must be used), High contrast, Dark theme. Reduced motion replaces flips with a fade.

Responsive: The grid and keys scale from 320px to desktop; keyboard keys have at least 44px touch height; use minmax(0,1fr) or flex with min-width:0 so nothing overflows at 390px.

Rules: Single HTML file with a Google Fonts link, inline CSS and JS, no libraries or external images. Add [hidden]{display:none!important}. Tiles have aria-labels like "A, correct"; an aria-live region announces results; the grid is role=grid; all toggles are role=switch. Wrap clipboard and localStorage in try/catch. Invented names only.
